# The Paycheck Effect

**A University of Colorado Employee Experience**

A standalone, scenario-based leadership simulation exploring how catch-up benefit deductions can affect an employee household's cash flow.

## Live URL after GitHub Pages is enabled

`https://krisblair82-pixel.github.io/the-paycheck-effect/`

## Files

- `index.html` — page structure and attribution
- `styles.css` — responsive styling
- `game.js` — scenarios, calculations, game state, and editable assumptions

## Publish with GitHub Pages

1. Create a public GitHub repository named `the-paycheck-effect` under `krisblair82-pixel`.
2. Upload all files from this folder to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub finishes deploying, visit:
   `https://krisblair82-pixel.github.io/the-paycheck-effect/`

## Editing assumptions

Open `game.js`. The `CONFIG` object at the top contains the primary financial assumptions, including rent, grocery costs, gas, tutoring, dental costs, payroll estimates, and the $250 safeguard.

## Alternative recovery model

The comparison applies the proposed **Standardized 1.5x Recovery with Net Pay Safeguard only to missed benefit deductions**. PERA catch-up, current PERA, imputed-income taxation, and other payroll items remain unchanged.

## Important limitation

This is an illustrative leadership simulation, not an official CU payroll calculator or benefits determination. Payroll amounts should be validated before the simulation is used as formal policy analysis.

## Inspiration

The project was inspired by **SPENT**, a scenario-based financial simulation created for Urban Ministries of Durham: https://playspent.org/

The Paycheck Effect uses original CU-focused scenarios, calculations, content, and design. No affiliation with or endorsement by SPENT or Urban Ministries of Durham is implied.
